# Úkol: Git základy

> **Pravidlo pro všechny commity:** zpráva musí krátce popisovat, co bylo přidáno
> (např. `Přidán prázdný soubor`). Zprávy typu `asdf` nebo `update` se nepočítají.

## Postup

### 1. Příprava
- [ ] Vytvořte **fork** tohoto repozitáře na GitHubu.
- [ ] Naklonujte si svůj fork do počítače.

### 2. První commit
- [ ] Vytvořte složku `studenti`.
- [ ] Ve složce vytvořte **prázdný** textový soubor se svým křestním jménem a názvem svého oblíbeného pokémona `jmeno-pokemon.txt` (např. `jarmil-charmander.txt`).
- [ ] Přidejte soubor a vytvořte **první commit**.

### 3. Druhý commit
- [ ] Do souboru napište, jaký zvuk váš pokémon vydává (nebo si zvuk vymyslete).
- [ ] Vytvořte **druhý commit**.

### 4. Třetí commit
- [ ] V konzoli spusťte příkaz `git log --oneline`.
- [ ] Výsledek vložte na konec souboru.
- [ ] Vytvořte **třetí commit**.

### 5. Odevzdání
- [ ] Pushněte změny na svůj fork.
- [ ] Na GitHubu vytvořte **pull request** do větve `main` **původního** (tohoto) repozitáře.
