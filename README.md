# Úkol

*Všechny commity musí mít ve zprávě krátký popis toho, co bylo přidáno (např. “Přidán prázdný soubor”).*

Vytvořte fork tohoto repozitáře a naklonujte si ho (git clone).
Vytvořte složku studenti a do ní vytvořte prázdný textový soubor pojmenovaný jmeno-pokemon.txt (např. jarmil-charmander.txt). Přidejte ho (git add) a vytvořte první commit.
Do souboru napište, jaký zvuk váš pokémon vydává (nebo si zvuk vymyslete). Vytvořte druhý commit.
Spusťte (příkaz do konzole) `git log --oneline` a výsledek vložte na konec souboru. Vytvořte třetí commit.
Pushněte změny na svůj fork.
Na GitHubu vytvořte pull request do větve main původního (tohoto) repozitáře.
